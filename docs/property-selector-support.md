# SANSA property selectors and selected Tonics dependencies

RC integration guidance, 24 November 2026. The active Titonic dependency is exact
public SANSA `0.15.0-rc.3`; the old private archive/root override is no longer its
install graph. Normal Tonics builds still consume the selected AEON TypeScript
sibling artifacts. Neither parser availability nor a neighboring checkout grants
an evaluator capability. [Inputs and qualification boundary](rc-registry-integration.md).

The coordinated AEON SDK supplies an authoritative property facet for read-only
Resolve/direct Query. Explicit portable AEOS entrypoints admit the selected
property profile; the legacy native-event validator stays closed. Titonic's own
namespace and guarded edit/apply/Graph/Instruction/SO/stored-activation/reference
consumers retain their existing admission contracts. This dependency update does
not authorize them to evaluate property predicates. Existing child-identity reads
and ordinary mutation behavior retain their separate contracts.

`aeon-search` exposes its documented path/prefix/value/datatype/kind search
options; it is not a general property-selector Query API. Do not infer support
from its name or display metadata. The [portable AEOS guide](https://github.com/AltoPelago/aeon/blob/110faa7f31dfe9f25c6dfb4bd52888eecf3e122e/docs/aeos-property-selectors.md)
and [SANSA contract](https://github.com/AltoPelago/sansa/blob/0b9316f6e31814377220ab3e5821d8457857d16c/docs/property-selectors-contract.md)
name the separately admitted entrypoints.

Qualify the exact installed graph and original target/compatibility controls.
A source build or a registry dependency pin alone does not prove a clean consumer,
new namespace capability, platform qualification or an independently published
Tonics package. Legacy sibling-layout and denied-consumer boundaries remain
explicit; no new source, profile, capability, allowance or mutation path is added.
The 1.15x latency / 1.20x memory budgets and existing narrowly recorded identity
qualification limit remain unchanged. No new benchmark or broader waiver.
